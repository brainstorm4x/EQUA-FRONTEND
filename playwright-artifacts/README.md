# Playwright E2E Test Artifacts

This directory contains screenshots and other artifacts generated by Playwright E2E tests.

## Screenshots

The following screenshots are captured during test execution:

- `referral-valid.png` - Valid referral code state
- `referral-used.png` - Used referral code state
- `referral-expired.png` - Expired referral code state
- `referral-not-found.png` - Not found referral code state
- `referral-public-key.png` - Valid public key input state
- `referral-malformed.png` - Malformed input state
- `threshold-optional.png` - Referral optional (below 100 users)
- `threshold-required.png` - Referral required (at/above 100 users)

## Generating Screenshots

Run the E2E tests to generate screenshots:

```bash
npm run test:e2e
```

## CI Artifacts

In CI environments, these artifacts are automatically uploaded and can be downloaded from the workflow run.
